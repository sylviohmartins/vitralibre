# VitraLibre Implementation Plan
> Execução autônoma autorizada pelo prompt mestre. Aplicar executing-plans; agentes independentes em pesquisa e núcleo.
**Goal:** editor local e catálogo exportável para dois segmentos.
**Architecture:** módulos nativos, contrato v1 em specs/design.md, gerador HTML independente, build estático sem backend.
**Tech Stack:** HTML/CSS/JS com JSDoc, Node test, GitHub Actions.
**Spec:** specs/design.md.
## Restrições
Sem segredos, sem ativos proprietários, P0 sem SaaS. Publicação só com resultado real. Backend P2.
## Review Focus
JSON malformado e IDs duplicados rejeitados; preços brasileiros corretos; XSS em textos/URLs não executa; quota local não anuncia salvamento; exportação funciona sem editor.
## Tarefas
- [ ] Núcleo: tests/core.test.mjs antes de src/core.js; schema, parsePrice, filterProducts, storage e gerador em src/export.js; Node test vermelho/verde.
- [ ] UI: src/app.js, src/styles.css e index.html; CRUD acessível consumindo o núcleo, modelos e SVG próprios em src/examples.js/public/assets.
- [ ] QA: build.mjs, testes integrais, browser mobile/teclado/exportação; corrigir defeitos e revalidar.
- [ ] Pesquisa: dossiês oito concorrentes e REA com evidências reais, comparar sem scores arbitrários.
- [ ] Distribuição: docs OSS/licença/CI, push e deploy Sites, tentativa GitHub público se API ou browser autenticado disponível; ZIP como fallback.
