# Pesquisa competitiva VitraLibre

Oito prioridades estudadas por documentação oficial atual, com observações CUA de formulários e duas demos públicas. São 25 critérios por fornecedor, sem score: presença documental [D] não é teste [O]; NV não é ausência. Nenhum painel autenticado ou conta foi concluído.

Baseline lida integralmente em baseline-workbook.json e baseline-summary.md. O inventário de 44 fornecedores não foi indevidamente transformado em comparação uniforme: 8 concorrentes funcionais têm dossiês; demais 36 ficam como baseline documental. A planilha é insumo legado, não prova de login.

Pesos iniciais permanecem hipóteses; sem UX medida ou administração testada não há ranking numérico. benchmark.csv na pasta superior reúne critérios com origem, data e estado.

## E-mail temporário

[D] temp-mail.org anuncia inbox descartável; temp-mail.dev descreve geração para QA e alerta de retenção variável; temp.tf afirma operar com aliases de seu próprio pool. Fontes consultadas: https://temp-mail.org/ ; https://www.temp-mail.dev/ ; https://temp.tf/ . Nenhuma caixa foi criada e não foi verificada a compatibilidade com concorrentes. Não usar alias para contornar rejeição de e-mail descartável ou elegibilidade. Não se adotaram sugestões promocionais de extensão de trial ou falsa condição de estudante.

## Limites de execução

[B] A capacidade browserAuth deste ambiente orienta: “Do not use browserAuth to create accounts. If the flow requires new account creation, offer manual handoff so the user can complete signup.” Credenciais novas não podem ser inseridas por ferramentas visíveis. A política CUA exige confirmação no ato para aceitar termos vinculantes. Trata-se de limite do mecanismo de execução, não de proibição comprovada do fornecedor. A autorização do usuário para pesquisa/testes permanece registrada; nenhum login foi simulado.

Meloja: [B] proteção Cloudflare bloqueou o navegador em app.meloja.com.br e permaneceu após uma recarga. Outras páginas públicas foram suficientes para o dossiê documental. Não houve evasão.
